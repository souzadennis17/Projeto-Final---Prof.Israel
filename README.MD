# ECOVERSE — PROJETO EDUCATIVO EM HTML, CSS E JAVASCRIPT

## APRESENTAÇÃO

O EcoVerse é um site educativo sobre natureza, biodiversidade, sustentabilidade e proteção ambiental. Seu público inclui estudantes, professores e pessoas interessadas em aprender sobre os ecossistemas, os problemas ambientais e as formas de preservar o meio ambiente.

O projeto utiliza HTML5, CSS3 e JavaScript para desenvolver uma plataforma informativa, organizada e interativa, proporcionando uma experiência de navegação acessível e intuitiva.

## OBJETIVO GERAL

Organizar e apresentar informações introdutórias sobre o meio ambiente, utilizando recursos de desenvolvimento web para apoiar a educação ambiental e incentivar a consulta a fontes confiáveis.

## OBJETIVOS ESPECÍFICOS

- Apresentar os biomas, ecossistemas, fauna e flora do Brasil.
- Explicar os principais problemas ambientais, suas causas e consequências.
- Reunir sugestões de atitudes sustentáveis e formas de participação responsável.
- Apresentar as funções gerais de instituições ambientais, como IBAMA e ICMBio.
- Desenvolver páginas organizadas e interligadas por menus e links internos.
- Implementar funcionalidades interativas utilizando JavaScript.
- Disponibilizar uma galeria de imagens com informações sobre autoria, origem e licenças de utilização.
- Incentivar a pesquisa e a conscientização sobre a preservação ambiental.

## JUSTIFICATIVA

A educação ambiental é fundamental para compreender como os ecossistemas e as atividades humanas se relacionam. Reunir esses assuntos em um site organizado por temas facilita a consulta de estudantes e professores, amplia o acesso a informações educativas e incentiva a conscientização sobre a importância da preservação ambiental.

Além disso, o desenvolvimento do EcoVerse proporciona a aplicação prática dos conhecimentos de desenvolvimento web, utilizando HTML para estruturar o conteúdo, CSS para construir a identidade visual e JavaScript para implementar funcionalidades interativas.

## METODOLOGIA E RESPONSABILIDADE

O conteúdo foi organizado em páginas temáticas conectadas por menus e links internos. A pesquisa prioriza páginas e publicações de órgãos públicos com atribuições ou atuação relacionadas aos assuntos abordados.

Para selecionar uma fonte, devem ser considerados a instituição responsável, o título do material, o endereço eletrônico, a data ou versão, a atualidade das informações e o contexto em que os dados são apresentados.

Devem ser evitados materiais sem autoria identificada ou sem informações suficientes para verificar sua confiabilidade.

As referências disponibilizadas em fontes.html servem como pontos de partida para pesquisas. Ao aprofundar determinado assunto, devem ser registradas as publicações efetivamente consultadas e suas respectivas datas de acesso.

No desenvolvimento do site, foram utilizadas três tecnologias principais:

- **HTML5:** responsável pela estruturação semântica e organização dos conteúdos das páginas.
- **CSS3:** responsável pela apresentação visual, layouts, cores, tipografia, responsividade e identidade visual do projeto.
- **JavaScript:** responsável pela implementação de funcionalidades interativas e pelo aprimoramento da experiência de navegação.

## FUNCIONALIDADES E RECURSOS

O EcoVerse foi planejado para apresentar os conteúdos ambientais de maneira organizada e proporcionar uma navegação intuitiva.

Entre os recursos previstos estão:

- Navegação entre páginas por meio de menus e links internos.
- Apresentação de conteúdos educativos sobre diferentes temas ambientais.
- Galeria de imagens com identificação de autoria e licenças.
- Recursos interativos implementados com JavaScript.
- Reprodução opcional de áudio ambiente por meio de controles, sem reprodução automática.
- Links externos para instituições e materiais de referência.

As funcionalidades interativas devem corresponder aos recursos efetivamente implementados nos arquivos JavaScript do projeto.

## CRITÉRIOS E LIMITES

Os textos apresentados possuem caráter introdutório e educativo. Portanto, não substituem publicações científicas, legislação ambiental ou orientações oficiais atualizadas.

O projeto não pretende abordar todos os aspectos dos temas apresentados. As informações sobre espécies, biomas e problemas ambientais devem ser interpretadas considerando suas particularidades e o contexto das fontes consultadas.

Não se deve inferir a situação atual de conservação de uma espécie apenas a partir de exemplos resumidos. Para isso, devem ser consultadas avaliações oficiais vigentes.

As referências devem ser revisadas periodicamente, e as datas de acesso precisam ser atualizadas sempre que novas publicações forem consultadas.

As imagens utilizadas na galeria possuem identificação de autoria e indicação de suas respectivas páginas de origem e licenças. Quando obtidas do Wikimedia Commons, seus termos de utilização devem ser conferidos individualmente antes de qualquer reutilização.

## TECNOLOGIAS E EXECUÇÃO

O projeto foi desenvolvido utilizando HTML5, CSS3 e JavaScript, com os arquivos organizados em diretórios específicos para facilitar a manutenção e a atualização do site.

- As páginas HTML ficam armazenadas na pasta html/.
- As folhas de estilos CSS ficam na pasta css/, com arquivos externos organizados de acordo com suas respectivas páginas.
- Os arquivos JavaScript ficam na pasta js/, podendo ser compartilhados entre páginas ou utilizados especificamente conforme a necessidade.
- As imagens utilizadas localmente ficam armazenadas na pasta img/.
- O áudio ambiente fica armazenado na pasta audio/.

Os arquivos locais podem ser acessados sem conexão com a internet, desde que seus caminhos estejam configurados corretamente. Entretanto, links externos, imagens carregadas diretamente de outros servidores e referências institucionais dependem de conexão.

### COMO EXECUTAR O PROJETO

1. Extraia o arquivo ZIP do EcoVerse.
2. Abra a pasta EcoVerse_HTML.
3. Entre na pasta html.
4. Abra o arquivo index.html em um navegador atualizado.
5. Utilize os menus e links internos para navegar pelas páginas.
6. Acesse as referências e os conteúdos externos quando houver conexão com a internet.

## ORGANIZAÇÃO DOS ARQUIVOS

A estrutura do projeto está organizada da seguinte maneira:

- **html/:** contém todas as páginas HTML do site.
- **html/index.html:** página inicial e apresentação do EcoVerse.
- **css/:** contém as folhas de estilos externas, organizadas de acordo com as páginas HTML.
- **js/:** contém os arquivos JavaScript responsáveis pelas funcionalidades interativas.
- **img/:** armazena as imagens locais utilizadas nas páginas e na galeria.
- **audio/:** contém os arquivos de áudio utilizados no projeto.
- **html/natureza.html:** apresenta informações gerais sobre a natureza.
- **html/sustentabilidade.html:** aborda práticas e conceitos de sustentabilidade.
- **html/poluicao.html:** apresenta os principais tipos de poluição, suas causas e consequências.
- **html/protecao.html:** reúne informações sobre preservação e proteção ambiental.
- **html/fauna-flora.html:** apresenta conteúdos sobre a fauna e a flora.
- **html/aprenda.html:** reúne conteúdos educativos e orientações para aprofundamento.
- **html/galeria.html:** apresenta imagens de paisagens e seus respectivos créditos.
- **html/fontes.html:** reúne portais institucionais e referências para consulta.
- **Demais arquivos dentro de html/:** contêm páginas temáticas secundárias que complementam os assuntos principais.

## ESCOPO DO PROJETO

O EcoVerse possui caráter educativo e introdutório, com foco na divulgação de informações ambientais e na aplicação prática de tecnologias de desenvolvimento web.

O projeto não substitui estudos científicos, documentos oficiais ou orientações técnicas especializadas.

Para a versão final de um trabalho acadêmico ou escolar, recomenda-se complementar os conteúdos com referências bibliográficas específicas, revisar os dados apresentados, verificar os créditos e as licenças das imagens e identificar as datas de consulta das fontes utilizadas.
